PDF 转 Word 工具
===============

使用方法
--------
1. 双击「启动.bat」，会自动打开浏览器窗口。
2. 把 PDF 文件拖入页面（或点击「选择文件」），可一次选多个。
3. 点击「开始转换」。
4. 转换完成后，生成的 Word 文档保存在本目录下的「输出」文件夹中，
   页面里可直接点「打开文件」或「打开所在文件夹」。

支持的类型
----------
- 文字版 PDF：直接提取文字，速度快、精度高。
- 扫描版 PDF（图片型）：自动 OCR 识别文字，并自动校正页面方向
  （例如横放扫描的表格）。首次识别需加载模型，稍慢（约 1-2 分钟/页）。
- 扫描件支持常见的图片格式：JPEG、PNG/FlateDecode、JPEG2000、CCITT 传真
  等（由 PDF.js 统一解码），不再局限于 JPEG。

识别语言
--------
- 自动（中文 + 英文）：适合中英混排文档。
- 中文（简体）：纯中文文档更精准。
- 英文：纯英文文档。

注意事项
--------
- 程序为本地运行，文件不会上传到网络，可放心使用。
- 扫描件的 OCR 结果可能存在少量识别错误，建议转换后人工校对。

依赖
----
需要电脑已安装 Node.js（https://nodejs.org）。
首次运行请确保已执行过 npm install（本目录已包含 node_modules 可直接运行）。
